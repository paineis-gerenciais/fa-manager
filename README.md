# FA Manager

Jogo de gerenciamento de futebol americano no navegador, com partidas narradas lance a lance. Funciona offline e guarda o jogo só no seu aparelho.

- Jogar: https://paineis-gerenciais.github.io/fa-manager/
- **Dados fictícios.** Times, jogadores, liga e competições são fictícios. A semelhança de alguns nomes com pessoas ou organizações reais é proposital e não indica vínculo, licença nem apoio.
- Licença dos dados da liga: [LICENCA-DADOS.md](LICENCA-DADOS.md).

Este repositório contém só a versão publicada (arquivos gerados). Versão 0.3.0.
